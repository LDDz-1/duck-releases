## 📖 使用指南

### 起步

1. 解压压缩包，进入 `鸭鸭伴侣` 文件夹
2. 双击 `鸭鸭伴侣.exe`
3. 鸭鸭会出现在桌面上，跟你说"你好"

### 网易云音乐

1. 鼠标移到鸭鸭区域，歌曲面板会出现**网易云图标**
2. 点图标 → 弹出登录面板 → 手机网易云 APP 扫码
3. 登录后，再次点击网易云图标，就能看到你的**歌单、日推、私人FM**
4. 点歌单直接在线播放，无需下载

### AI 分析

鸭鸭会在放歌时自动分析情绪。如果 AI 已配好（内测版默认配好了），它会在歌的关键段落冒出**思维气泡**——不是模板句，是真实针对这首歌的碎碎念。

如果不想听它说话：右键鸭鸭 → **"我想静一静"**。再点一次恢复。

如果 AI 没配好（或 API 用完了）：右键鸭鸭 → **AI设置**，填上自己的 API：
- 协议：OpenAI-compatible 或 Anthropic-compatible
- 地址：你的 API 地址
- 模型：模型名称
- Key：你的 API 密钥
- 点"测试连接"确认能用 → 保存

### MBTI 性格

右键鸭鸭 → **MBTI**

鸭鸭有 16 种 MBTI 性格，默认 INF🐥。切换后鸭鸭的说话风格、话多话少、表情动作全都会变。

推荐试试 ENFP（话痨小太阳）和 INTJ（冷静哲学家）的对比。

### 和鸭鸭聊天

右键鸭鸭 → **"我有话想和你说..."**

鸭鸭会根据当前在放什么歌、之前你的听歌记录、它的 MBTI 性格来回复你。不是生硬的机器人对话，更像一个一起听歌的朋友。

### 桌面玩法

- 鸭鸭窗口是**透明悬浮**的，不挡其他应用
- **拖拽鸭鸭**可以移动它在桌面上的位置
- 系统托盘里有鸭鸭图标，右键可以显示/隐藏/退出
- 播放模式可以切换：顺序 / 随机 / 单曲循环（进度条右侧按钮）

### 常见问题

**Q: 双击 exe 没反应？**<br>
A: Windows 可能会弹安全提示，点"更多信息" → "仍要运行"。

**Q: AI 不说话？**<br>
A: 检查 API 设置是否配好。右键鸭鸭 → AI设置 → 测试连接。如果显示"我想静一静"，右键鸭鸭 → 点"我想听你说说"恢复。

**Q: 怎么关掉鸭鸭？**<br>
A: 点鸭鸭旁边红色退出按钮，或在系统托盘右键鸭鸭 → 退出。
